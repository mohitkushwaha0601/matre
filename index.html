How to use the collection

These materials are built as self-contained HTML pages so they work directly in the browser, in VS Code preview, and on GitHub Pages without a build step. That keeps the workflow lightweight and consistent with the static study-set approach used in this project.

Recommended sequence: start with the national security handbooks, then move to geopolitics and political concepts, and finish with the map and ideology guides for pattern recognition and recall.
